# Web Animation Run - design and integrate browser motion

One job: plan, implement, and verify an animation integrated into a website, app, or interactive browser experience.

| Stage | Job | Output |

| [`stages/02_motion_plan/CONTEXT.md`](stages/02_motion_plan/CONTEXT.md) | Specify motion behavior and reduced-motion behavior | `motion-plan.md` |
| [`stages/03_implementation/CONTEXT.md`](stages/03_implementation/CONTEXT.md) | Implement in the application source tree | `implementation-record.md` |
| [`stages/04_verify_handoff/CONTEXT.md`](stages/04_verify_handoff/CONTEXT.md) | Verify and record handoff | `release-handoff.md`, `check.md` |

Read `../../_shared/project-profile.md` and `../../_shared/animation-principles.md` when a stage names them. A stage is complete only when its check passes.
