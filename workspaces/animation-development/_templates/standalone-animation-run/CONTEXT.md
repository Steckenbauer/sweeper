# Standalone Animation Run - plan, produce, and deliver 2D/3D motion

One job: turn a standalone 2D/3D animation request into an approved plan, production, and verified delivery.

| Stage | Job | Output |
|---|---|---|
| [`stages/01_scope/CONTEXT.md`](stages/01_scope/CONTEXT.md) | Define audience, purpose, and delivery requirements | `animation-brief.md` |
| [`stages/02_storyboard/CONTEXT.md`](stages/02_storyboard/CONTEXT.md) | Plan shots, timing, and visual progression | `storyboard.md` |
| [`stages/03_production/CONTEXT.md`](stages/03_production/CONTEXT.md) | Create the editable project and render | `production-record.md` |
| [`stages/04_verify_handoff/CONTEXT.md`](stages/04_verify_handoff/CONTEXT.md) | Verify playback and export handoff | `release-handoff.md`, `check.md` |

Read `../../_shared/project-profile.md` and `../../_shared/animation-principles.md` when a stage names them. A stage is complete only when its check passes.
