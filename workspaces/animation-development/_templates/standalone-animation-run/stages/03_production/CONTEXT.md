# 03_production - create editable animation and render

One job: produce the approved animation using the configured toolchain.

## Inputs
- Working (this run): `../01_scope/output/animation-brief.md`
- Working (this run): `../02_storyboard/output/storyboard.md`
- Reference (every run): `../../../../_shared/project-profile.md`
- Reference (every run): `../../../../_shared/animation-principles.md`

Do NOT invent unavailable software or move project assets into this run folder.

## Process
1. Stop if the brief/storyboard is missing or unchecked, or if required tools/settings are unavailable.
2. Create or update editable project files in the agreed source location.
3. Produce a preview or render using the configured settings.
4. Record tools, settings, asset locations, render location, and exact checks performed.

## Outputs
- `production-record.md` -> `output/`
- Editable project and render -> the locations named in the brief and project profile

## Check
Review the production record and preview against the approved storyboard and settings. Record `pass` or `fail: <why>` under `## Stage Check`.
