# 02_storyboard - plan sequence and timing

One job: create a reviewable visual plan before production begins.

## Inputs
- Working (this run): `../01_scope/output/animation-brief.md`
- Reference (every run): `../../../../_shared/animation-principles.md`
- Reference (every run): `../../../../_shared/project-profile.md`

## Process
1. Stop if the brief is missing, unchecked, or lacks agreed delivery requirements.
2. Divide the animation into beats or shots with composition, action, and transitions.
3. Map beats to the agreed duration and frame rate; note audio or visual dependencies.
4. Identify assets, technical risks, and the planned review/render checkpoints.

## Outputs
- `storyboard.md` -> `output/`

## Check
The requester or creative owner approves the sequence, timing, and visual direction before production. Record `pass` or `fail: <why>` under `## Stage Check`.
