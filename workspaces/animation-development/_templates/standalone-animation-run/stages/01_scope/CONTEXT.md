# 01_scope - define animation and delivery requirements

One job: make the animation's purpose, scope, and delivery criteria explicit.

## Inputs
- Working (this run): `../../request.md`
- Reference (every run): `../../../../_shared/animation-principles.md`
- Reference (every run): `../../../../_shared/project-profile.md`

Do NOT infer an editor, renderer, output format, or technical delivery setting that is not specified.

## Process
1. Stop if the story/purpose, audience, delivery destination, or required technical settings are unclear.
2. Define the intended message and acceptance criteria.
3. Confirm applicable duration, frame rate, dimensions/aspect ratio, color, audio, and export settings.
4. Confirm where editable sources and rendered outputs belong.

## Outputs
- `animation-brief.md` -> `output/`

## Check
The requester confirms the brief and delivery requirements. Record `pass` or `fail: <why>` under `## Stage Check`.
